Privacy first

This demo is designed for a local Ollama endpoint. Keep the endpoint on your own computer. Do not enter private client information into an AI system unless you understand where the data is processed.

How to set up local AI

  1. Install Ollama from its official website.
  2. Open a terminal and run ollama pull qwen2.5:3b.
  3. Start the model using ollama run qwen2.5:3b.
  4. Serve this website through a local development server.
  5. Configure Ollama to accept requests from your website's local origin.
  6. Return here and select Test connection.

Browser cross-origin restrictions may prevent requests until Ollama's allowed origins are configured. Do not expose the local API publicly. Model requirements depend on your computer.
